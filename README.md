# IziBook

Скорочтение методом **RSVP** (Rapid Serial Visual Presentation): слова показываются по одному в фиксированной точке экрана, взгляд не бегает по строке — поэтому читать можно в 2–3 раза быстрее обычного.

**by [FoxyEvil](https://t.me/F0xyEvil)**

## Возможности

- Загрузка книг: `.txt`, `.epub` (распаковка через JSZip) или вставка текста.
- Количество слов в кадре — от **1 слова** до **целого предложения**: режимы `1 / 2 / 3 / 4 / 6 / Авто / Предложение`.
- Скорость в «словах в минуту» (WPM) с пресетами и кнопками `±`.
- Точка фиксации: буква в центре строки + вертикальная линия. Режимы подсветки: **всё / буква / штрих / ничего**.
- Паузы на знаках препинания, навигация по абзацам и главам (оглавление).
- Автосохранение позиции чтения, светлая/тёмная тема, шрифт с/без засечек, размер шрифта.
- PWA: можно «Добавить на главный экран» на телефоне.

## Как запустить

- **Компьютер / Android:** откройте `index.html` (или нужную версию) в браузере — работает локально.
- **iPhone:** локальный `.html` через «Файлы» открывается в предпросмотре без JavaScript. Откройте страницу по HTTPS (GitHub Pages) или скачайте сборку из [Releases](https://github.com/yourolga777/IziBook/releases).

## Горячие клавиши

`Пробел` — пауза · `←/→` — кусок · `↑/↓` — скорость · `PgUp/PgDn` — абзац · `Home` — начало · `O` — подсветка · `Esc` — назад.
