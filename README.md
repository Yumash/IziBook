# IziBook

Скорочтение методом **RSVP** (Rapid Serial Visual Presentation): слова показываются по одному в фиксированной точке экрана, взгляд не бегает по строке — поэтому читать можно в 2–3 раза быстрее обычного.

## Возможности

- Загрузка книг: `.txt`, `.epub` (JSZip) или вставка текста
- Кадр: `1 / 2 / 3 / 4 / 6 / Авто / Предложение`
- Скорость WPM, паузы на знаках, ORP-подсветка
- Оглавление, автосохранение позиции, светлая/тёмная тема
- PWA-лайт: «Добавить на главный экран» (без полноценного офлайна)

## Как запустить

- **Онлайн:** Pages из корня `main` — `index.html` (настройки репозитория менять не нужно).
- **Компьютер / Android:** откройте `index.html` в браузере (модули подхватятся рядом).
- **iPhone (локально):** через «Файлы» JS часто отключён — используйте онлайн-версию.
- **Локальный сервер (опционально):** `npm run serve`

## Как выпустить версию

1. Синхронизировать номер в `package.json` и `js/state.js` (`IziBook.VERSION`).
2. Закоммитить изменения в `main`.
3. Создать и запушить тег:

```bash
git tag v3.2.0
git push origin v3.2.0
```

4. GitHub Actions соберёт single-file HTML + `samples.zip` и создаст Release.

Не кладите новые версии отдельными файлами в корень (`IziBook-vX.html`) — для этого есть **теги и Releases**.
