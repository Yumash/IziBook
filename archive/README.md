# Архив старых версий

Здесь лежат исторические **монолитные** HTML (v1.0 → v3.1) до разбиения на модули.

Они **не** используются сайтом и релизами. Актуальный код — в корне репозитория.

Чтобы «откатить» поведение старой версии для себя — откройте нужный файл в браузере или скачайте артефакт из GitHub Releases (после перехода на semver-теги).
