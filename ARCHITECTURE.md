# Архитектура IziBook

Скорочтение методом **RSVP**: текст превращается в последовательность кадров (chunks), которые показываются в одной точке экрана.

## Поток данных

```
.txt / .epub / paste
        │
        ▼
   files.js  ──►  сырой текст
        │
        ▼
  parser.js  ──►  абзацы → предложения → слова
        │
        ▼
  chunks.js  ──►  кадры (по mode: N слов / авто / предложение)
        │
        ▼
  player.js  ──►  таймер WPM + ORP-подсветка → #word
        ▲
        │
  storage.js ──  настройки + позиция (localStorage)
  ui.js / main.js ── события интерфейса
```

## Модули (`js/`)

| Файл | Ответственность |
|------|-----------------|
| `state.js` | Версия, настройки, runtime текущей книги |
| `utils.js` | `$`, hash, ORP-индекс, эвристика кириллицы |
| `parser.js` | Нормализация текста → дерево абзацев |
| `chunks.js` | Построение кадров и списка глав |
| `player.js` | Рендер кадра, play/stop, навигация |
| `storage.js` | localStorage настроек и прогресса |
| `files.js` | Чтение .txt (кодировки) и .epub (JSZip) |
| `ui.js` | Шторки, TOC, `startReading`, применение настроек к DOM |
| `pwa.js` | Иконка + manifest (без Service Worker) |
| `main.js` | Точка входа: обработчики событий |

Общий namespace: `window.IziBook`. Скрипты **не** ES modules — так страница открывается и через GitHub Pages, и локально как `file://`.

## Почему `index.html` в корне

GitHub Pages у репозитория настроены как **branch `main` + folder `/`**.  
Вход приложения должен оставаться `index.html` в корне, иначе сайт `*.github.io/IziBook/` перестанет открываться после merge.

## Релизы

Пошаговый чеклист для человека и AI-агента — в **[AGENTS.md](AGENTS.md)** (раздел «Когда пользователь просит сделать релиз»).

Кратко: версия в `package.json` + `js/state.js` → тег `vX.Y.Z` → workflow `release.yml` → GitHub Release.  
Старые монолиты — в `archive/`; продукт — `index.html` + `css/` + `js/` в корне.

## Известные ограничения

- EPUB: упрощённый разбор OPF, без nav/NCX; DRM не поддерживается; нужен интернет для JSZip.
- Hash позиции: `djb2(первые 5KB + длина)` — редкие коллизии у разных книг возможны.
- PWA без Service Worker: полноценного офлайна нет.

## Исправления при разбиении (v3.2.0)

- TOC: детектор «Глава / Chapter» больше не опирается на `\b` (в JS не работает с кириллицей).
- Прогресс-бар: защита от деления на ноль при пустой книге.
